# Семинар по теме "Введение в RAG"

Состоит из нескольких тюториалов:

- _llm.ipynb_                   -- учимся подавать запросы к LLM с помощью библиотеки _openai_
- _faiss.ipynb_                 -- знакомимся с векторными индексами на примере _faiss_
- _sbert.ipynb_                 -- ранжируем документы с использованием библиотеки _sentence_transformers_
- _rag_langchain.ipynb_         -- создаем RAG-систему на _langchain_

Чтобы запустить ноутбуки у себя, надо создать виртуальное окружение так, как описано в [корневом README](../../README.md)

ВНИМАНИЕ: на данный момент этот семинар работает только с python <= 3.13!

Для запуска _faiss.ipynb_ нам понадобится самостоятельно скачать эмбеддинги word2vec и положить их в папку _models_ по пути _models/word2vec/GoogleNews-vectors-negative300.bin_ (ссылка для скачивания есть в ноутбуке).
