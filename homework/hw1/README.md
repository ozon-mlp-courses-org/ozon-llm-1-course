# ДЗ 1

Выполните задания из ноутбука.

Можно использовать любые модели, а не только рассмотренную на семинаре. Чем меньше будет модель на которой получится решить задачу приемлемо -- тем лучше (промптить маленькие модели сложнее). В этом случае можно рассчитывать на 10 баллов по задаче из 10, даже если не все тесты пройдут успешно.

Данные для тестов нужно взять из директории data соответствующего семинара.

В конечном итоге должен получиться ноутбук с исполненными ячейками (можно с тем же названием), который необходимо закоммитить в ваш форк данного репозиторий и создать Pull Request. В его описании или комментариях тегайте [@VictorDotZ](https://github.com/VictorDotZ).

Удачи с ДЗ!
